
# Therapy Site — Frontend Web Development Assignment

A fully redesigned therapy practice homepage for **Dr. Maya Reynolds, PsyD** — built using **Next.js**, **TypeScript (TSX)**, **Tailwind CSS**, and a modern responsive layout.

This project was created as part of the **Grow My Therapy Internship Assignment (Stage 2: Practical Assignment)** and demonstrates UI cloning, theme redesign, copywriting, responsive layout, and custom sections including an “Our Office” section.

## 🎯 Objective

Redesign and clone the homepage template (originally lilac-themed) and enhance it for a fictional therapist profile — **Dr. Maya Reynolds, PsyD** — using the provided profile text as the single source of truth.

This includes:

- Pixel-perfect cloning of the source template
- Tailored redesign with a cohesive theme
- SEO-optimized content based on therapist profile
- Custom section: **Our Office**
- A responsive, modern UX/UI across devices

## 💻 Installation & Running Locally

1. **Clone repository**
   ```bash
   git clone https://github.com/priyankasharma1603/Therapy-site.git
````

2. **Install dependencies**

   ```bash
   cd therapy-site
   npm install
   ```

3. **Run development server**

   ```bash
   npm run dev
   ```

4. **Open in browser**

   ```
   http://localhost:3000
   ```

## 🚀 Build & Deployment

To create a production build:
